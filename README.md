# Hospital Readmission Management Dashboard

![Hospital Readmission Dashboard](Hospital_Readmission_Dashboard_Preview.png)

## Project Overview

This project presents an interactive Hospital Readmission Management Dashboard created in Microsoft Excel.

The dashboard analyses hospital readmission patterns across patient age groups, primary diagnoses and medical specialties. It provides hospital management teams with a clear overview of readmission performance and supports data-driven decisions aimed at improving patient outcomes and operational efficiency.

## Business Problem

Hospital readmissions can indicate gaps in discharge planning, follow-up care and patient management. This dashboard was developed to help stakeholders identify patient groups and clinical areas with higher readmission rates.

## Project Objectives

The analysis aims to answer the following questions:

- What percentage of patients were readmitted?
- Which age groups have the highest readmission rates?
- Which primary diagnoses show higher readmission levels?
- Which medical specialties experience higher readmission rates?
- How many patients were readmitted compared with those not readmitted?
- What is the average length of hospital stay?

- Approximately 47% of patients in the analysed dataset were readmitted.
- Readmission rates vary across age groups, diagnoses and medical specialties.
- Some primary diagnosis groups show readmission rates above 50%.
